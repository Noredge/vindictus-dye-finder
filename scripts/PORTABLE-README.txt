Vindictus Dye Finder - Preview 0.3.2

Windows x64 portable build. No .NET installation needed.
Extract the entire ZIP, then open VindictusDyeFinder.exe.
Keep all files together; do not run the EXE from inside the ZIP.

Open a screenshot (or Ctrl+V), choose colors, then Find Matches.
Try Demo opens a real example. Click a numbered point for a closer view.
Colors are estimates; preview the result in game.

Record Result saves local feedback. Open Feedback Folder finds the ZIPs.
Nothing uploads automatically. Review feedback before sharing it.
