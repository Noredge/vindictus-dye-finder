Vindictus Dye Finder - Web Preview 0.1 (local trial)

1. Extract the entire ZIP to a folder.
2. Double-click Start-Web.cmd. Node.js 24 must be available on this computer.
3. Choose Try Demo, or Open Screenshot. Choose colors, then Find Matches.
4. Click any of the six numbered points to inspect the shared zoom preview.
5. Record Result or Report a Problem downloads a local feedback ZIP.
6. Double-click Stop-Web.cmd when finished to stop this folder's local server.

The local address is http://127.0.0.1:4173/ . No npm install or build is needed
for this packaged preview. Do not open dist/index.html directly as a file.

Images and search stay in your browser. Nothing uploads automatically.
Only settings persist in the browser; reopen your image after refreshing.
RGB values are screenshot estimates. Preview the result in game.
Optional feedback screenshots require crop review before being attached.

This is a local preview, not a published website. Chrome and the Codex
Chromium browser were checked. Edge/Firefox/Safari, more real screenshots,
color profiles/JPEG/transparency/EXIF, browser zoom/high DPI, actual clipboard
and drag/drop, and full performance/memory acceptance remain to be verified.

Application license and game artwork notices are included in dist/.
