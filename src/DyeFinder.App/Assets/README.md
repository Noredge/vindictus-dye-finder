# Artwork and example

`DyeFinder.ico` / `DyeFinder.png` are the original project paintbrush icon, generated from vector drawing commands in `scripts/New-Icon.ps1`. They are covered by the project's MIT license.

`DemoScreenshot.png` is a 270 × 375 crop from a user-supplied Vindictus screenshot (`2026_09_12_0032.png`), included at the user's request for a real example. Crop rectangle in the original 2560 × 1440 image: (1127, 512, 270, 375). No resize, recoloring or synthetic pixels are used. It contains only the color board, its six crosses and the six RGB labels; no chat, names or character view is included.

The app detects this crop through the same geometry detector used for imported images. This demonstrates the workflow, not a claim of accuracy on unseen boards. Feedback from it is identified as `bundled-real-demo` and should not be counted as an independent live-game trial.

The game screenshot is reference material; its game artwork remains the property of the respective rights holders and is not licensed under the application's MIT license.
